---

## 📋 الخطوات التفصيلية (Step-by-Step)

1. **تهيئة بيئة العمل والتثبيت (Setup & Installation):**
   - فتح موجه الأوامر (Terminal) والتوجه إلى المجلد الخاص بـ المشروع.
   - تثبيت مكتبة `FastAPI` ومحرك التشغيل `Uvicorn`.

2. **إنشاء ملف التطبيق الرئيسي (`main.py`):**
   - إنشاء ملف Python جديد باسم `main.py`.
   - استيراد `FastAPI` وإنشاء كائن التطبيق الأساسي (`app`).

3. **تعريف المسار الرئيسي (Root Endpoint):**
   - إضافة نقطة نهاية (Endpoint) من نوع `GET` على المسار الرئيسي `/`.
   - كتابة دالة ترجع استجابة بصيغة `JSON` للتأكد من عمل السيرفر بنجاح.

4. **تشغيل السيرفر المحلي (Development Server):**
   - تشغيل التطبيق عبر خادم `Uvicorn` مع تفعيل وضع التحديث التلقائي (`--reload`).

5. **استعراض التوثيق التفاعلي (Interactive API Documentation):**
   - فتح المتصفح والانتقال إلى `/docs` للوصول إلى واجهة **Swagger UI**.
   - مراجعة وتجربة الـ Endpoints مباشرة من المتصفح.

---

## 💻 الأوامر البرمجية (Commands) وشرحها

### 1. تثبيت المكتبات المطلوبة

```bash
pip install fastapi uvicorn
```

* **`pip install`**: أمر تثبيت الحزم والمكتبات الخارجية في Python.
* **`fastapi`**: إطار عمل سريع جداً ومخصص لبناء الـ Web APIs مع دعم كامل لـ Async و Pydantic.
* **`uvicorn`**: خادم ASGI خفيف وسريع يُستخدم لتشغيل تطبيقات FastAPI.

---

### 2. تشغيل سيرفر التطبيق

```bash
uvicorn main:app --reload
```

* **`uvicorn`**: أداة تشغيل السيرفر.
* **`main`**: اسم ملف البايثون (`main.py`).
* **`:app`**: كائن تطبيق FastAPI المُعرف داخل الملف (`app = FastAPI()`).
* **`--reload`**: خيار تفعيل التحديث التلقائي (Hot Reload)؛ يعيد تشغيل السيرفر تلقائياً بمجرد حفظ أي تعديل في الكود دون الحاجة لإعادة التشغيل يدوياً.

---

### 3. تحديد المضيف والمنفذ (اختياري)

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

* **`--host 0.0.0.0`**: للسماح باستقبال الطلبات من الأجهزة الأخرى على نفس الشبكة المحلية.
* **`--port 8000`**: تحديد رقم المنفذ (Port) الخاص بالسيرفر.

## 📝 كود التطبيق الأساسي (`main.py`)

```python
from fastapi import FastAPI

# إنشاء كائن التطبيق
app = FastAPI(title="mini-RAG API")

# تعريف المسار الرئيسي
@app.get("/")
async def root():
    return {"message": "Welcome to mini-RAG API"}
```
